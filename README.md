# 🗳️ Landing Page — Campanha Política

Este repositório contém a página web (landing page) desenvolvida para a apresentação de propostas, divulgação de materiais de campanha e interação com os eleitores.

## 🎯 Objetivo
Proporcionar uma plataforma moderna, leve e responsiva para apresentar as ideias da campanha, facilitando a comunicação direta com o público e o engajamento digital.

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estruturação da página)
* **CSS3** (Design responsivo e estilização)
* **JavaScript** (Interatividade e dinamismo)
